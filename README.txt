ADRIANA KOLEVA - GIS PORTFOLIO WEBSITE
======================================

Files
  index.html       the website (layout and design)
  projects.js      ALL the text: projects, descriptions, skills, captions
  img/             the map images
  slr-poster.html  the full Sea Level Rise poster

To preview: double-click index.html.

Publish it for free (pick one)
  Netlify (fastest): go to app.netlify.com/drop, sign up free, and drag this
  whole folder onto the page. You get a link like your-name.netlify.app.
  To update it later, drag the updated folder onto your site's "Deploys" page.

  GitHub Pages (best long-term): create a free GitHub account, make a new
  public repository called "portfolio", upload all files in this folder,
  then Settings > Pages > Branch: main > Save. Your link will be
  https://YOUR-USERNAME.github.io/portfolio/

Edit it yourself
  Open projects.js in any text editor (Notepad, TextEdit, or straight on
  GitHub with the pencil icon). Change text between the quotes and save.
  New images go in img/ as .jpg, referenced by name without ".jpg".
